Sign in

The admin saves trips straight into your GitHub repository, so it needs a GitHub access token. It stays in this browser only and is never put on the site.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Under Repository access pick Only select repositories and choose homecoming.
  3. Under Permissions, set Contents to Read and write. Generate the token and paste it below.
